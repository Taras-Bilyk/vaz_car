# VAZ 2107 RC CAR

<img src="screenshots/scr_1.png" width="400">

## 🤨 Навіщо ?:
просто цікавий проект

## 🤓 Опис:
це міні модель машини на керуванні по WIFI мережі з джостика

## ☠️ Використані технології:
- прошивка на MICROPYTHON
- GUI сервера на KIVY
- під капотом працює на UDP SOCKETS
- події джостика сервер читає через PYGAME

## 🌱 Структура проекта:
- `screenshots/` — скріншоти і фотографії
- `stl_objects/` - 3D модельки, які можна надрукувати повторно
- `server.py` — головний файл для запуска сервера
- `main.py` — головний файл прошивки

## 😇 Фічі:
- підключенн стабільне на всій площі покриття WIFI
- біле ближнє світло
- дальнє біле світло
- жовті блимаючі поворотники
- жовта блимаюча аварійка
- задні білі вогні при русі назад
- задні червоні габарити
- червоні яскраві стоп сигнали при нажатті на тормоз
- задній привід (1 мотор нан кожному задньому колесі, сумарно 2)
- на передніх колесах стоять сервомотори для поворотім (1 мотор на кожному передньому колесі, сумарно 2)
- рух вперед
- рух назад
- повороти

## 🌚 Компоненти які для збірки:
- ESP32-WROOM (1x)
- щітковий звичайний мотор на 5-7 вольт (2х)
- сервомотори MG90 Micro Servo (2х)
- понижувач LM2596 струму (2х)
- акумулятор на 7.4 вольта (1х)
- дроти
- пприпой
- червоні світлодіоди (2х)
- білі світлодіоди (6х)
- жовті світлодіоди (4х)
- драйвери моторів L298N (2х)

## 🥺 Принцип роботи:
- джостик передає дані про натиснення на ноутбук
- сервер на ноуттбуці обробляє ці сигнали і відправляє команди по WIFI на ESP32 (тобто машинку)
- ESP32 виконує ті команди які вона отримує по WIFI

## ⚠️ ПОПЕРЕДЖЕННЯ:
- прошивка працює ЛИШЕ на ESP32-WROOM

## 😎 Як це запустити ?:
1. встановлюємо необхідні пакети на пк/ноутбук
```bash
sudo apt update
sudo apt install python3
sudo apt install python3-pip python3-dev libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev libportmidi-dev libswscale-dev libavformat-dev libavcodec-dev zlib1g-dev libgstreamer1.0-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good
pip install "kivy[base]"
sudo pip3 install adafruit-ampy
```
2. змінюємо ось ці рядки в файлі `main.py` на ваші дані:
```python
wifi_module.connect('YOUR_WIFI_SSID', 'YOUR_WIFI_PWD')
ip_of_computer = 'YOUR_IP_OF_PC_WHERE_SERVER_IS_RUNNING'
```
4. заисуємо прошивку на ESP32
```bash
ampy --port /dev/ttyUSB0 put main.py
```
4. вмикаємо машину кнопкою на дверях
5. підключаємо джостик до пк/ноута
6. запускаємо сервер
```bash
python3 server.py
```
7. машина підключиться автоматично
